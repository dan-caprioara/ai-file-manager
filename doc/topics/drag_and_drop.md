# Drag and Drop Functionality in File Manager

The AI Manager now includes a Drag and Drop (DnD) feature in the File Manager, allowing users to add files to the current folder by simply dragging and dropping them from other applications. This enhances the ease of managing files and improves productivity.

## Using Drag and Drop

- **Basic DnD Operation**: Click and drag the files from your source application and drop them into the desired folder in the File Manager.
- **Copying Files**: To copy the files instead of moving them, hold down the `CTRL` key while performing the drag and drop operation.
