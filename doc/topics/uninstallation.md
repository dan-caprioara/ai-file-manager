# Uninstallation

## Uninstalling AI Manager on Windows

To uninstall the AI Manager application from a Windows operating system, follow these steps:

1. Open the **Settings** app on your Windows device. This can be done by clicking the Start menu and selecting **Settings**.
2. Navigate to **Apps**.
3. Under the **Apps & features** section, scroll through the list or use the search function to locate **AI Manager**.
4. Click on **AI Manager** and select **Uninstall**.
5. Follow the prompts to complete the uninstallation process.

This procedure removes the AI Manager application but retains your user data and configurations should you choose to reinstall later. For complete removal, manually delete any remaining user data from your system.
