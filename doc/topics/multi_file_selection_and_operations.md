# Multi-File Selection and Operations

AI Manager now supports multi-file selection in its dual-panel interface, similar to Norton Commander style. This feature allows users to select multiple files using common keyboard and mouse combinations and perform operations such as copy and move from the source panel to the destination panel.

## How to Select Multiple Files
- **Keyboard**: Hold down the `CTRL` key (or `COMMAND` on Mac) and click on the files you wish to select.
- **Mouse**: Click and drag to select multiple files sequentially.

## Operations on Selected Files
Once files are selected, you can:
- **Copy**: Use the `CTRL + C` (or `COMMAND + C` on Mac) shortcut or right-click and select 'Copy'.
- **Move**: Use the `CTRL + X` (or `COMMAND + X` on Mac) shortcut or right-click and select 'Move'.

Selected files can be transferred from one panel to the other, enhancing file management efficiency.
