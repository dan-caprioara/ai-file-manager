# Zoom and Font Controls in AI Manager

AI Manager now includes zoom and font control features to enhance user experience. These features are accessible via buttons located below the two main browse panels in the interface.

## Zoom In and Zoom Out

- **Shortcut Keys**:
  - On Windows and Linux, use `CTRL +` to zoom in and `CTRL -` to zoom out.
  - On Mac, use `COMMAND +` to zoom in and `COMMAND -` to zoom out.

## Button Appearance

- The zoom in and zoom out buttons are designed with bold icons to make them easily identifiable.

## Notes

- Ensure that your application is updated to the latest version to utilize these features.
- If you encounter any issues with overlapping panels when zoomed in, check for updates as this issue has been addressed in the latest patches.
